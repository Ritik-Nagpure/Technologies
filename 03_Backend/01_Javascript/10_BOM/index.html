Feature Description
window.alert() Displays a popup alert box
window.confirm() Shows a confirmation dialog with OK/Cancel
window.prompt() Opens a dialog box that prompts the user for input
window.open() Opens a new browser window or tab
window.close() Closes the current browser window
window.setTimeout() Executes a function after a specified delay
window.setInterval() Repeats execution of a function at set intervals
window.clearTimeout() Cancels a timeout set with setTimeout()
window.clearInterval() Cancels an interval set with setInterval()
window.location Provides access to the current URL and allows navigation
window.history Enables navigation through browser history
window.navigator Gives information about the browser and device
window.screen Provides details about the user's screen
window.document Refers to the DOM document loaded in the window
window.innerWidth Width of the viewport
window.innerHeight Height of the viewport
window.scrollTo() Scrolls the window to a specific position
window.print() Opens the print dialog
window.focus() Brings the window to the foreground
window.blur() Removes focus from the window
window.onresize Event triggered when the window is resized
window.onerror Handles errors that occur in the window
window.localStorage Stores data locally with no expiration
window.sessionStorage Stores data for the duration of the page session
window.fetch() Performs network requests (modern alternative to XMLHttpRequest)
window.crypto Provides cryptographic functions
window.matchMedia() Checks if the document matches a media query
window.requestAnimationFrame() Optimizes animations by syncing with browser refresh rate

Document Access (via BOM)
  • When you open a webpage, the browser loads its HTML and creates a structured representation called the Document Object Model (DOM).
  • The BOM gives you access to the DOM via window.document, allowing JavaScript to interact with the content of the page.
  • This Interact will be then done using DOM Manupulations.

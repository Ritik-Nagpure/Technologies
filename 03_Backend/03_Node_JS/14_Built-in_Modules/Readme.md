## 🧰 Built-in Modules in Node.js

Built-in modules are already installed with Node.js, so you don’t need to install them using any package manager like `npm` or `yarn`.

### 📦 Module Reference Table

| Module           | Description                                                                 |
|------------------|-----------------------------------------------------------------------------|
| `fs`             | Dealing with the system files.                                              |
| `os`             | Provides information about the operating system.                           |
| `net`            | Used to build clients and servers.                                          |
| `path`           | Handles file paths.                                                         |
| `url`            | Helps in parsing URL strings.                                               |
| `http`           | Enables Node.js to transfer data over HTTP.                                |
| `console`        | Logs information to the console.                                            |
| `assert`         | Provides a set of assertion tests.                                          |
| `process`        | Gives information about and control over the current process.              |
| `cluster`        | Creates child processes that run simultaneously and share the same port.   |
| `perf_hooks`     | Provides APIs for performance measurement.                                  |
| `crypto`         | Handles OpenSSL cryptographic functions.                                    |
| `Buffer`         | Manages streams of binary data.                                             |
| `dns`            | Enables name resolution.                                                    |
| `events`         | Handles existing events and creates custom events.                          |
| `child_process`  | Allows spawning of subprocesses.                                            |
| `repl`           | Provides a Read-Eval-Print Loop (REPL) interface.                           |
| `readline`       | Reads data from a stream one line at a time.                               |
| `util`           | Supports internal Node.js APIs.                                             |
| `querystring`    | Parses and formats URL query strings.                                       |
| `string_decoder` | Decodes Buffer objects into strings.                                        |
| `tls`            | Implements TLS and SSL protocols.                                           |

---

📚 *Visit the official [Node.js documentation](https://nodejs.org/api/) to learn more about each module.*

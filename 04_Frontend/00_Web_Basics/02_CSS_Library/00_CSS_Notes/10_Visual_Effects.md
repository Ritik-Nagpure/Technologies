## Visual Effects : Enhance the look and feel of elements.

Interview One-Liner: Visual effects add depth, emphasis, and polish to designs.

## Opacity : Control transparency of elements.

Interview One-Liner: Opacity sets how visible or transparent an element is.

```css
/* make element 50% transparent */
div {
  opacity: 0.5;
}
/* fully visible */
div {
  opacity: 1;
}
```

## Box Shadow : Add shadow around elements.

Interview One-Liner: Box shadow creates depth by casting shadows.

```css
/* simple shadow */
div {
  box-shadow: 5px 5px 10px gray;
}
/* inset shadow */
div {
  box-shadow: inset 0 0 10px black;
}
```

## Text Shadow : Add shadow behind text.

Interview One-Liner: Text shadow makes text stand out with shadow effects.

```css
/* shadow behind text */
h1 {
  text-shadow: 2px 2px 4px #000;
}
```

## Filters : Apply visual effects like blur or brightness.

Interview One-Liner: Filters modify how elements are rendered visually.

```css
/* blur image */
img {
  filter: blur(5px);
}
/* increase brightness */
img {
  filter: brightness(150%);
}
/* grayscale effect */
img {
  filter: grayscale(100%);
}
```

## Backdrop Filter : Apply effects to background behind an element.

Interview One-Liner: Backdrop filter styles the area behind an element.

```css
/* blur background behind element */
div {
  backdrop-filter: blur(10px);
}
/* add brightness to background */
div {
  backdrop-filter: brightness(120%);
}
```

## Gradients : Create smooth color transitions.

Interview One-Liner: Gradients blend multiple colors seamlessly.

```css
/* linear gradient background */
div {
  background: linear-gradient(to right, red, yellow);
}
/* radial gradient background */
div {
  background: radial-gradient(circle, blue, green);
}
```

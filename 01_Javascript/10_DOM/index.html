Modifying attributes

The dataset is a special property in JavaScript that lets you access and manipulate custom data attributes on HTML elements — those that start with data-. 

<div id="userCard" data-user-id="123" data-role="admin"></div>

const div = document.getElementById('userCard');
console.log(div.dataset.userId); // "123"
console.log(div.dataset.role); // "admin"
